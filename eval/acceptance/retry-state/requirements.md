# 重试验收演示的确认输入

这是工作流机制的本地演示规格，不代表实际业务后端已确认或联调完成。核心行为沿用 eval/cases/retry-state/prd.md；以下额外契约与超时规则只用于本演示，不回写原评测 PRD，不改变原 fixtures 基线。

1. 点击加载进入 loading；GET /api/profile 成功展示返回的完整 JSON，状态为 success。
2. HTTP 非 2xx、网络失败、200 响应带 error 对象时，状态为 failed；展示错误且有可用重试入口。没有自动重试。
3. 重试发起新的 GET；成功展示新响应 JSON，原错误清除，重试入口隐藏。
4. loading 时重复点击加载或重试，不并行发第二个请求；完成后允许下一次请求。
5. 客户端等待 1500ms 后主动超时并取消请求；进入 failed、显示“请求超时，请重试”，可以重试恢复。测试框架超时不能作为此项通过。
6. 演示成功契约为 {"name":"Ada","revision":1} 等 name 字符串、revision 整数；契约错误必须被联调验收报告，不能改 fixture 掩盖。

来源界限：原 PRD 明确成功/加载/HTTP 失败/恢复/重复操作；业务失败、网络失败及具体超时阈值是本演示定义的额外测试规则。真实项目须以自己的确认需求和项目规则替换。
