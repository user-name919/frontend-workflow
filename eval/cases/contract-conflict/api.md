# API：GET /api/students

归属：**后端仓库**（本前端仓只消费）。

## 当前响应

```json
[
  { "id": 1, "name": "Lin" },
  { "id": 2, "name": "Chen" }
]
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 学生 ID |
| name | string | 学生姓名 |

## 明确不包含

- **不提供** `guardianMobile` 或任何监护人联系方式字段。
- 后端排期未包含该字段；前端需求若依赖该字段，属于 **CONTRACT_GAP**，需产品/后端确认后另立接口变更。

## 所有权

接口定义与实现归后端。前端 Agent 不得假装已添加字段，也不得在前端写死假手机号冒充接口数据来“完成”需求。
