# PRD：请求失败后支持重试

## 目标

在现有「个人资料」加载页增加失败后的重试能力，不改变原有成功路径。

## 范围

- 前端行为：加载状态、失败展示、重试触发。
- 不改后端接口契约；仍请求 `/api/profile`。

## 角色

终端用户查看自己的资料。

## 可观察行为

1. 点击「加载」后进入加载中状态。
2. 请求成功时展示资料 JSON，状态为成功。
3. 请求失败时展示失败信息，并提供可点击的「重试」。
4. 加载进行中再次点击加载/重试，不得并行发出第二次请求（沿用或保持 in-flight）。

## 异常状态

- HTTP 非 2xx：进入失败态，允许重试。
- 重试成功后回到成功态。

## 非目标

- 不引入自动轮询。
- 不实现登录或权限模型。

## 验收要点（给实现者的摘要）

成功、加载、失败、重复点击四类场景均需可演示；成功路径与基线一致。
